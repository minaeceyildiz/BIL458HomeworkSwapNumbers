# BIL458HomeworkSwapNumbers
# Homework 1 - Swap Two Numbers

## Description
This project is a simple Python program that swaps two numbers entered by the user.

## Requirements
- Python 3.x must be installed on your system.

## How to Run
1. Open a terminal or command prompt.
2. Navigate to the project folder:
   cd swap-numbers
3.Run the script:
   python swap_numbers.py
4.Enter two numbers when prompted. The program will swap them and display the result.

Build Instructions:
No build process is required since this is a Python script. Just ensure you have Python installed.
